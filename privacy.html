Privacy policy

Last updated: November 3, 2026.

Glasshouse Bridge is a private tool used by one person, the owner of the Google account dubeauxg@gmail.com, for their Glasshouse app studio. It runs on that person's own computer.

What it can access

It asks Google for two permissions, and nothing else:

  • Send email (gmail.send). It sends summary emails only to the account it is signed in to. It cannot read, search or delete any email.
  • Calendars it creates (calendar.app.created). It creates one calendar, "Glasshouse Studio", and adds, changes and removes events on that calendar only. It cannot see any other calendar or event.

It does not access contacts, files, location or any other Google data.

What it stores

The sign-in token Google issues is kept in the macOS keychain on the owner's computer. The tool keeps a small local record of what it has already sent and which events it created, so it does not repeat them. The content of the emails and events comes from the studio's own project tracker on the same computer.

Sharing

Nothing is sold, shared with third parties, used for advertising or analytics, or used to train AI models. Data moves only between the owner's computer and the owner's own Google account.

Glasshouse Bridge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from myaccount.google.com/permissions. Deleting the "Glasshouse Studio" calendar removes every event the tool created.
