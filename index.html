Glasshouse Bridge

Glasshouse Bridge is a private, single-user tool for the Glasshouse app studio. It runs on the studio owner's own computer and keeps one Google account informed about the studio's work: it adds events to a calendar it created itself, and it sends short summary emails to that same account.

It is not offered to the public, and nobody else can sign in to it.
